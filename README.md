# 📡 Radio Connect - جهاز لاسلكي

تطبيق ويب عربي يحاكي جهاز لاسلكي (Walkie-Talkie) مع صوت لاسلكي عسكري،
محادثة فورية، رسائل صوتية، وإدارة غرف — مبني بـ LiveKit + Node.js.

## ✨ الميزات

- 🎙️ **Push-To-Talk (PTT)** — اضغط باستمرار للتحدث
- 📻 **صوت لاسلكي عسكري** — 4 أنواع (أساسي / ثقيل / حاد / كلاسيكي)
- 🎧 **صوت طبيعي** — بدون فلتر
- 💬 **محادثة فورية** — عبر LiveKit DataChannel
- 🎙️ **رسائل صوتية** — تسجيل وإرسال (مثل واتساب)
- 📎 **إرفاق ملفات** — صور / فيديو / مستندات / صوت
- 👥 **إدارة الأعضاء** — موافقة / رفض / حذف
- ⭐ **المفضلة** — حفظ الغرف للوصول السريع
- 📻 **موجات متعددة** — تنقل بين 4 موجات
- 🔋 **حالة الجهاز** — البطارية / الشبكة / الاتصال
